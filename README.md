# leonardofaoro.com

Personal portfolio website. Single-page, minimal, dark-mode aware.

## Stack

- HTML5 (single page, semantic sections)
- Tailwind CSS v3.4 (utility-first, dark mode via `class`)
- Vanilla JavaScript (IIFE)
- Deployed to Cloudflare Pages

## Quick start

```sh
make install   # install dependencies
make dev       # start Tailwind in watch mode + open http://localhost:8080
make run       # serve static files on :8080
```

## Commands

| Command         | Description                              |
| --------------- | ---------------------------------------- |
| `make install`  | Install npm dependencies                 |
| `make dev`      | Tailwind watch mode                      |
| `make run`      | Serve files on port 8080                 |
| `make build`    | Compile Tailwind CSS                     |
| `make deploy`   | Minify assets and deploy to Cloudflare   |
| `make clean`    | Remove node_modules, dist, style.css     |

## Development notes

- **Tailwind needs a rebuild** after adding new utility classes to HTML — `npm run build` scans HTML and only generates CSS for classes found.
- **`overflow-x: hidden` on both `<html>` and `<body>`** — body alone is not enough; overflowing content escapes body and causes scroll on html.
- **Long text on mobile** — avoid `truncate` (`white-space: nowrap`) inside flex rows; it doesn't reliably shrink. Prefer wrapping (`break-all` for unbreakable strings), or switch to CSS Grid with `minmax(0, 1fr)` if truncation is mandatory.
- **Dark mode** — class-based (`<html class="dark">`), toggle button + `Cmd/Ctrl+Shift+L` shortcut.

## Deploy

```sh
make deploy
```

Requires `CLOUDFLARE_API_TOKEN`. Minifies HTML, JS, and CSS into `dist/` and deploys to Cloudflare Pages.
