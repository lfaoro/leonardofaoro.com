# Project: leonardofaoro.com

## Overview
Personal portfolio website of Leonardo Faoro. Minimal, single-page site showcasing open-source projects, payment methods, and contact info.

## Tech Stack
- HTML5 (single page, semantic sections)
- Tailwind CSS v3.4 (utility-first, dark mode via `class`)
- Vanilla JavaScript (IIFE, no frameworks)
- No build step beyond Tailwind compilation
- Deployed to Cloudflare Pages via Wrangler

## Architecture
```
├── index.html          # Main page (single file)
├── 404.html            # Error page
├── src/
│   ├── input.css       # Tailwind directives + custom components
│   ├── style.css       # Generated by Tailwind (gitignored)
│   └── script.js       # All JS functionality
├── assets/             # Images, keys, QR codes
├── old/assets/         # Deprecated/unused assets
├── sw.js               # Service Worker (v3, stale-while-revalidate)
├── manifest.json       # PWA manifest
├── sitemap.xml         # Auto-updated on deploy
├── robots.txt          # Allow all
├── security.txt        # Security contact info
├── tailwind.config.js  # Dark mode: 'class', content paths
├── package.json        # tailwindcss, terser, html-minifier-terser
└── Makefile            # build, deploy, dev commands
```

## Key Features
- Dark/light mode toggle (localStorage persistence, system preference fallback)
- Active nav indicator (IntersectionObserver, amber dot)
- Scroll-triggered fade-in animations (threshold: 0.2)
- Mobile menu (focus trap, outside click, Escape close)
- Copy-to-clipboard with toast notifications
- Live GitHub stats with localStorage caching (1h TTL)
- Service Worker for offline support

## Tailwind Custom Components (input.css)
- `.header-blur` — frosted glass header
- `.card` — bordered rounded boxes with hover lift
- `.btn-primary` — dark button (inverts in dark mode)
- `.link-muted` — subtle links with slide-in underline hover
- `.nav-active` — active nav item with amber dot
- `.gh-loading` — GitHub stat skeleton pulse animation

## Design System
- **Palette**: Neutral grays (50-950) + amber-500 accent
- **Typography**: System font stack, no custom fonts
- **Spacing**: Tailwind defaults, `px-6` containers, `max-w-6xl` max width
- **Border radius**: `rounded-xl` cards, `rounded-lg` buttons
- **Shadows**: Only on card hover (`shadow-lg`)

## Dark Mode
- Class-based: `<html class="dark">`
- Toggle button + `Cmd/Ctrl+Shift+L` shortcut
- All components have `.dark` variants
- Theme color meta tags for browser chrome

## Mobile Strategy
- `sm:` breakpoint (640px) for nav toggle
- `min-h-screen` sections fill viewport
- Touch targets minimum 44×44px
- `overflow-x: hidden` on **both** `<html>` and `<body>` — body alone is not enough; overflowing content escapes body and causes scroll on html
- Safe area insets for notched devices
- `touch-action: manipulation` on interactive elements
- **Long text on mobile**: avoid `truncate` (white-space: nowrap) inside flex rows — `flex-1 min-w-0` doesn't reliably constrain nowrap content. Prefer wrapping:
  - Text with spaces (GPG keys, IBAN): just drop `truncate`, let it wrap naturally
  - Text without spaces (SSH keys, crypto addresses): use `break-all` to force character-level wrapping
- If truncation is mandatory, switch from flex to CSS Grid with `grid-cols-[minmax(0,1fr)_auto]` — grid tracks with `minmax(0, 1fr)` shrink below content size, unlike flex items

## Deployment (Makefile)
1. `make build` — compile Tailwind CSS
2. `make deploy` — create `dist/`, minify assets, deploy via Wrangler
   - HTML minified (html-minifier-terser)
   - JS minified (terser)
   - CSS already minified by Tailwind
   - Sitemap `lastmod` auto-updated to today
3. Cloudflare Pages project: `leonardofaoro`

## Environment
- `CLOUDFLARE_API_TOKEN` required for deploy
- No other env vars needed

## Important Notes
- **Tailwind CSS build after HTML changes** — `npm run build` scans HTML for classes and only generates CSS for those found. Any new utility class (e.g. `overflow-hidden`, `flex-1`) added to HTML needs a CSS rebuild or it won't exist in `style.css`.
- **Service Worker cache** — bump `CACHE_NAME` version when changing assets
- **Avatar** — `w-[40vw]` with `max-w-80` cap, centered in `h-screen` hero
- **Footer** — ultra-minimal, single centered line, `pb-8` spacing
